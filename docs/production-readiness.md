# 正式环境上线清单

当前 Next.js 应用提供本地演示模式及正式部署安全默认值。演示数据和 mock 的训练/健康文本不应视为医疗建议。

## 环境

1. 将 `.env.example` 复制为 `.env.local`，设置 `DATABASE_URL`、`OPENAI_API_KEY` 和 `OPENAI_MODEL`。
2. 设置 `DEMO_MODE=false`。生产构建要求配置持久化 MySQL 8；本地配置数据库后运行 `npm run db:generate` 与 `npm run db:migrate`。
3. 对生产环境执行数据库迁移。应用运行时数据库角色仅授予所需表权限；迁移使用独立凭证。
4. 对 `app/api` 配置正式身份认证、基于会话的用户授权、来源/CSRF 校验和按用户/IP 限流。正式环境下 API 目前默认拒绝个人档案、餐食和 AI 访问，不允许以演示用户 ID 代替身份验证。
5. 加密静态备份、定义数据保留与删除政策、用户同意与导出流程，并核实隐私/合规要求。

## AI 与健康安全

- 当前安全检查与知识检索工具是透明标注的基线实现，不是临床验证的分类器，也不是真正的 RAG 检索服务。
- 上线前连接经医学/营养专业审核、具备版本和来源元数据的知识库；为检索、模型、餐食工具建立权限隔离、审计与滥用测试。
- 确认用户餐食前必须保留用户编辑/确认环节；不以模型输出替代专业诊断、治疗或个体营养处方。
- 配置模型超时、重试上限、Token/成本预算、PII 最小化和不记录敏感提示词的日志策略。
